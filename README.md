# OfferFlow AI

A hackathon project exploring how Meta AI models can turn messy supplier information into structured, verifiable price lists.

Developed by IN.TRA.M s.r.o. for the Meta Global AI Developer Hackathon, organized by Cerebral Valley.

## Status

Planning and specification stage. No application implementation, working demo, benchmark results or completed integrations are included yet.

## Intended scope

- Accept supplier documents through direct upload.
- Interpret and normalize product information using Meta models.
- Validate transformations with deterministic checks.
- Request human clarification when information is ambiguous.
- Export a traceable price list.

These are planned capabilities, not claims of completed functionality.

## Data and project boundary

Public examples will use synthetic data. This project is separate from the pre-existing commercial CatalogOps AI product. No proprietary CatalogOps code, customer records, supplier information, commercial margins or credentials are included.
