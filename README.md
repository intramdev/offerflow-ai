# OfferFlow AI

Supplier information arrives in spreadsheets, PDFs, images and messages. Turning it into a usable price list often means checking inconsistent descriptions, missing details and conflicting figures by hand.

We're building OfferFlow AI to make that work easier, using Meta AI to interpret supplier documents and checks that help people review the result.

Built by **IN.TRA.M s.r.o.** for the **Meta Global AI Developer Hackathon**, organized by Cerebral Valley.

## What we're building

A workflow for uploading supplier files, reviewing product information, resolving unclear details and exporting a price list that can be checked against its sources.

Development is at an early stage. A working demo, setup instructions and evaluation results will follow as the project takes shape.

## Development and data

Examples will use synthetic data. This repository contains the new hackathon work; it does not include proprietary application code or real supplier and customer records.

[NEW_WORK.md](NEW_WORK.md) describes the starting point and work completed during the event.
